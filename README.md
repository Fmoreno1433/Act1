# Prácticas de Git y GitHub

## 1. Descripción del proyecto

Este repositorio se ha creado como parte de las prácticas de despliegue de aplicaciones web. Su objetivo es aprender a utilizar Git para controlar las versiones de un proyecto y GitHub para alojar el código y colaborar con otros desarrolladores.

## 2. Objetivos

* Crear y gestionar archivos mediante Git.
* Registrar cambios utilizando commits.
* Subir los cambios a un repositorio remoto.
* Crear Releases para identificar versiones.
* Gestionar tareas y errores mediante Issues.
* Guardar cambios temporales con `git stash`.
* Documentar el proyecto utilizando Markdown.
* Excluir archivos innecesarios con `.gitignore`.
* Crear ramas e integrar cambios mediante `git merge`.

## 4. Tecnologías y herramientas

* **Git:** sistema de control de versiones distribuido.
* **GitHub:** plataforma para alojar repositorios y colaborar.
* **Markdown:** formato utilizado para documentar el proyecto.
* **Terminal:** interfaz para ejecutar comandos Git.

## 5. Flujo de trabajo

1. Crear o modificar archivos.
2. Revisar los cambios con `git status`.
3. Preparar los archivos con `git add`.
4. Registrar los cambios con `git commit`.
5. Subirlos a GitHub mediante `git push`.
6. Crear ramas para desarrollar funcionalidades independientes.
7. Integrar los cambios mediante `git merge`.

## 6. Versiones

La primera versión del proyecto se identifica con la etiqueta `v1.0.0`, asociada a una Release de GitHub cuando esta se haya publicado.
